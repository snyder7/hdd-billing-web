# v3.1 - app khud update hoga

Is version se purana app dobara kholte hi naya code utha leta hai (cache ki dikkat khatam).

## GitHub par
1. Add file -> Upload files: index.html aur sw.js (baaki files same hain).
2. Commit changes. 1-2 minute ruko.

## Phone par (sirf ek baar, agar abhi bhi purana dikh raha ho)
1. Chrome mein tab band karo (tab switcher mein X) aur link naye tab mein kholo. Sirf app ko band karne se tab reload nahi hota.
2. Phir bhi "v2/v3" purana dikhe to link ke end mein ?v=31 lagao, jaise .../REPO/?v=31
3. Phir bhi na ho: address bar ke paas icon -> Site settings -> Clear & reset. (Data Firebase mein safe hai, bas dobara login karna hoga.)
4. Home screen wala app ho to: icon dabake rakho -> App info -> Storage -> Clear cache.

Neeche "Powered by Silicon Traders • v3.1" dikhe to update ho gaya.
